# Correlation coefficient panel for pairs function

Correlation coefficient panel for pairs function.

## Usage

``` r
panel.cor(x, y, digits = 2, prefix = "", cex.cor)
```

## Arguments

- x:

  first data series

- y:

  second data series

- digits:

  number of digits to plot

- prefix:

  text to prefix the coefficients

- cex.cor:

  character expansion factor
