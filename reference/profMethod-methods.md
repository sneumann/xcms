# Get and set method for generating profile data

These methods get and set the method for generating profile (matrix)
data from raw mass spectral data. It can currently be `bin`, `binlin`,
`binlinbase`, or `intlin`.

## Methods

- object = "xcmsRaw":

  `profMethod(object)`
