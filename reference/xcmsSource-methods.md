# Create an [`xcmsSource`](https://sneumann.github.io/xcms/reference/xcmsSource-class.md) object in a flexible way

Users can define alternate means of reading data for
[`xcmsRaw`](https://sneumann.github.io/xcms/reference/xcmsRaw-class.md)
objects by creating new implementations of this method.

## Methods

- `signature(object = "xcmsSource")`:

  Pass the object through unmodified.
